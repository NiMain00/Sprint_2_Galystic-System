# App Bengkel Lathifah - Aplikasi Manajemen Bengkel

## Fitur
- Dashboard stats ^amp; recent transactions
- Live search di tables
- Quick pelanggan select untuk transaksi
- CSV export laporan
- Modern UI

## Development
```
build.bat  # Builds installer ^amp; bundle in dist/
```

## Bundle ^amp; Installer (Production Ready)
1. **Installer**: `dist/AppBengkel-Installer.exe`
   - Install ke Program Files
   - Auto shortcuts (Desktop/Start Menu)
   - Bundled JRE ^amp; SQLite

2. **Portable ZIP**: `dist/AppBengkel-Bundle.zip`
   - Extract ke folder
   - Run `run.bat` or double-click EXE/JAR
   - DB auto-init if missing
